# The Joke About the Demo

Entry for the make.fun bounty
[the-joke-about-the-demo-20261123-0112](https://make.fun/c/the-joke-about-the-demo-20261123-0112)

`main.py` (Python 3.13, standard library only) writes a one-line joke about
working beside an AI coding agent to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
